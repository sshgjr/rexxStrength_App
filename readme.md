# Rexx Strength — 3대 운동 점수 측정 알고리즘

## 개요

사용자가 업로드한 운동 영상을 분석하여 자세를 평가하는 시스템입니다. 전체 파이프라인은 디바이스에서 로컬로 실행됩니다.

### 파이프라인

```
영상 입력 → 프레임 추출 (5FPS) → ML Kit BlazePose (33개 랜드마크) → 규칙 기반 평가 → 점수 산출
```

1. `video_thumbnail`으로 200ms 간격(5FPS) JPEG 프레임 추출
2. Google ML Kit PoseDetector로 프레임별 33개 관절 좌표(x, y, z) 추출
3. 운동별 규칙 엔진이 관절 각도·정렬·대칭성을 분석하여 기준별 점수 산출
4. 가중 평균으로 총점 계산

## 공통 점수 계산 함수

### 관절 각도 계산 (`AngleCalculator.calculateAngle`)

세 점 A, B, C에서 꼭짓점 B의 각도를 3D 벡터 내적으로 계산합니다.

```
cos(θ) = dot(BA, BC) / (|BA| × |BC|)
각도 = acos(cos(θ)) × 180 / π    → 0°~180°
```

### 수직 각도 계산 (`AngleCalculator.calculateVerticalAngle`)

두 점의 Y축(수직선) 대비 기울기를 측정합니다.

```
각도 = atan2(|Δx|, |Δy|) × 180 / π
```

### 범위 기반 점수 (`AngleCalculator.rangeScore`)

측정값이 이상 범위 내에 있으면 100점, 벗어나면 선형 감점합니다.

```
idealMin ≤ value ≤ idealMax  →  100점
그 외  →  100 × (1 - deviation / tolerance)    (최소 0점)
```

### 좌우 대칭 점수 (`AngleCalculator.symmetryScore`)

좌우 각도 차이가 5° 이내면 100점, 20° 차이에서 0점으로 선형 감점합니다.

```
차이 ≤ 5°   →  100점
차이 > 5°   →  100 × (1 - (차이 - 5) / 15)    (최소 0점)
```

### 등급 체계

| 등급 | 점수 범위 | 표시 |
|------|-----------|------|
| Good | 85 ~ 100 | 좋음 |
| Warning | 50 ~ 84 | 주의 |
| Bad | 0 ~ 49 | 개선 필요 |

**총점 = Σ (기준별 점수 × 가중치)**

## 1. 스쿼트 (Squat)

| # | 평가 기준 | 가중치 | 측정 방법 |
|---|-----------|--------|-----------|
| 1 | 무릎 각도 | 30% | 엉덩이-무릎-발목 각도 (바텀 기준) |
| 2 | 힙 힌지 | 20% | 어깨-엉덩이-무릎 각도 |
| 3 | 무릎-발끝 정렬 | 20% | 무릎과 발끝의 X좌표 차이 |
| 4 | 척추 각도 | 15% | 어깨-엉덩이 수직 각도 |
| 5 | 좌우 대칭 | 15% | 좌우 무릎 각도 차이 |

### 1-1. 무릎 각도 (30%)

전체 프레임에서 **최소 무릎 각도**(바텀 포지션)를 측정합니다.

- **측정 관절**: 왼쪽 엉덩이 → 왼쪽 무릎(꼭짓점) → 왼쪽 발목
- **채점 기준**:
  - ≤ 90° → 100점 (충분한 깊이)
  - \> 90° → `rangeScore(value, idealMin=0, idealMax=90, tolerance=40)`
  - 즉, 130° 이상이면 0점

### 1-2. 힙 힌지 (20%)

전체 프레임에서 **최고 점수**를 채택합니다.

- **측정 관절**: 왼쪽 어깨 → 왼쪽 엉덩이(꼭짓점) → 왼쪽 무릎
- **이상 범위**: 70° ~ 90°
- **허용 오차**: 25°
- 45° 미만 또는 115° 초과 시 0점

### 1-3. 무릎-발끝 정렬 (20%)

전체 프레임의 **평균 점수**를 사용합니다.

- **측정**: 왼쪽 무릎과 왼쪽 발끝(foot index)의 X좌표 차이
- **채점 기준**:
  - X 차이 0 → 100점
  - X 차이 ≥ 0.15 → 0점
  - 선형 보간: `(1 - xDiff / 0.15) × 100`

### 1-4. 척추 각도 (15%)

전체 프레임에서 **최고 점수**를 채택합니다.

- **측정**: 왼쪽 어깨 → 왼쪽 엉덩이 수직 각도
- **이상 범위**: 60° ~ 80°
- **허용 오차**: 25°

### 1-5. 좌우 대칭 (15%)

전체 프레임의 **평균 점수**를 사용합니다.

- **측정**: 좌우 엉덩이-무릎-발목 각도의 차이
- **채점**: 차이 ≤ 5° → 100점, 20° 차이 시 0점

## 2. 벤치프레스 (Bench Press)

| # | 평가 기준 | 가중치 | 측정 방법 |
|---|-----------|--------|-----------|
| 1 | 팔꿈치 각도 | 25% | 어깨-팔꿈치-손목 각도 (바텀 기준) |
| 2 | 팔꿈치 벌어짐 | 25% | 팔꿈치-어깨-엉덩이 각도 |
| 3 | 바 경로 | 20% | 손목 X좌표의 표준편차 |
| 4 | 락아웃 | 15% | 어깨-팔꿈치-손목 각도 (최대) |
| 5 | 좌우 대칭 | 15% | 좌우 팔꿈치 각도 차이 |

### 2-1. 팔꿈치 각도 (25%)

전체 프레임에서 **최고 점수**를 채택합니다.

- **측정 관절**: 왼쪽 어깨 → 왼쪽 팔꿈치(꼭짓점) → 왼쪽 손목
- **이상 범위**: 85° ~ 95° (바텀에서 약 직각)
- **허용 오차**: 25°
- 60° 미만 또는 120° 초과 시 0점

### 2-2. 팔꿈치 벌어짐 (25%)

전체 프레임의 **평균 점수**를 사용합니다.

- **측정 관절**: 왼쪽 팔꿈치 → 왼쪽 어깨(꼭짓점) → 왼쪽 엉덩이
- **이상 범위**: 30° ~ 55° (몸통과 약 45° 각도)
- **허용 오차**: 25°
- 5° 미만 또는 80° 초과 시 0점

### 2-3. 바 경로 (20%)

손목 X좌표의 일관성을 측정합니다.

- **측정**: 전체 프레임에서 왼쪽 손목 X좌표 수집 → 분산(variance) 계산
- **채점 기준**:
  - 분산 0 → 100점
  - 분산 ≥ 0.01 → 0점
  - 선형 보간: `(1 - variance / 0.01) × 100`
- 프레임 2개 미만 시 기본 50점 (Warning)

### 2-4. 락아웃 (15%)

전체 프레임에서 **최대 팔꿈치 각도**를 측정합니다.

- **측정 관절**: 왼쪽 어깨 → 왼쪽 팔꿈치(꼭짓점) → 왼쪽 손목
- **채점 기준**:
  - ≥ 170° → 100점 (완전 신전)
  - < 170° → `rangeScore(value, idealMin=170, idealMax=180, tolerance=30)`
  - 140° 미만 시 0점

### 2-5. 좌우 대칭 (15%)

전체 프레임의 **평균 점수**를 사용합니다.

- **측정**: 좌우 어깨-팔꿈치-손목 각도의 차이
- **채점**: 차이 ≤ 5° → 100점, 20° 차이 시 0점

## 3. 데드리프트 (Deadlift)

| # | 평가 기준 | 가중치 | 측정 방법 |
|---|-----------|--------|-----------|
| 1 | 힙 힌지 패턴 | 25% | 고관절 vs 무릎 각도 변화량 비율 |
| 2 | 등 각도 | 25% | 어깨-엉덩이 수직 각도 (초반 30%) |
| 3 | 락아웃 | 20% | 어깨-엉덩이-무릎 각도 (최대) |
| 4 | 무릎 각도 | 15% | 엉덩이-무릎-발목 각도 (초반 30%) |
| 5 | 좌우 대칭 | 15% | 좌우 어깨·엉덩이 높이 차이 |

### 3-1. 힙 힌지 패턴 (25%)

**고관절 각도 변화량이 무릎 각도 변화량보다 큰지** 확인합니다.

- **측정**:
  - 고관절 각도: 어깨 → 엉덩이(꼭짓점) → 무릎
  - 무릎 각도: 엉덩이 → 무릎(꼭짓점) → 발목
  - 각각의 변화량(최대 - 최소) 계산 후 비율(ratio = hip / knee) 산출
- **채점 기준**:
  - ratio ≥ 1.5 → 100점 (올바른 힙 힌지)
  - 1.0 ≤ ratio < 1.5 → 70 + 30 × (ratio - 1.0) / 0.5
  - ratio < 1.0 → 70 × ratio (무릎 주도 = 감점)
  - 무릎 변화량 0 → 100점
- 프레임 2개 미만 시 기본 50점

### 3-2. 등 각도 (25%)

**초반 30% 프레임**에서 **최고 점수**를 채택합니다.

- **측정**: 왼쪽 어깨 → 왼쪽 엉덩이 수직 각도
- **이상 범위**: 30° ~ 50°
- **허용 오차**: 20°
- 10° 미만 또는 70° 초과 시 0점

### 3-3. 락아웃 (20%)

전체 프레임에서 **최대 고관절 각도**를 측정합니다.

- **측정 관절**: 왼쪽 어깨 → 왼쪽 엉덩이(꼭짓점) → 왼쪽 무릎
- **채점 기준**:
  - ≥ 170° → 100점 (완전 신전)
  - < 170° → `rangeScore(value, idealMin=170, idealMax=180, tolerance=30)`
  - 140° 미만 시 0점

### 3-4. 무릎 각도 (15%)

**초반 30% 프레임**에서 **최고 점수**를 채택합니다.

- **측정 관절**: 왼쪽 엉덩이 → 왼쪽 무릎(꼭짓점) → 왼쪽 발목
- **이상 범위**: 140° ~ 160° (살짝 굽힌 상태)
- **허용 오차**: 20°
- 120° 미만 또는 180° 초과 시 0점

### 3-5. 좌우 대칭 (15%)

전체 프레임의 **평균 점수**를 사용합니다.

- **측정**: 좌우 어깨 Y좌표 차이 + 좌우 엉덩이 Y좌표 차이의 평균
- **채점 기준**:
  - 차이 0 → 100점
  - 차이 ≥ 0.08 → 0점
  - 선형 보간: `(1 - diff / 0.08) × 100`
  - 어깨 점수와 엉덩이 점수의 평균을 최종 점수로 사용

## 운동 단계 감지 (Phase Detection)

각 운동에 대해 프레임 시퀀스를 5단계로 분류합니다.

| 단계 | 설명 |
|------|------|
| Setup | 준비 자세 |
| Descent | 하강 (이센트릭) |
| Bottom | 최저점 (전환) |
| Ascent | 상승 (컨센트릭) |
| Lockout | 완전 신전 |

- **스쿼트**: 무릎 각도 최소점 = Bottom
- **벤치프레스**: 팔꿈치 각도 최소점 = Bottom
- **데드리프트**: 고관절 각도 최소점 = Bottom (바닥에서 시작)
