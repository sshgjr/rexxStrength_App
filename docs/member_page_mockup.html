회원 페이지 UI 개선 — 비포 / 애프터

기존 회원 페이지가 라이트 머티리얼 기본값으로 렌더되어 다크 테마와 동떨어져 있고, 등급/소스 상태가 하드코딩되어 있었음. 다른 화면과 동일한 다크 그린 카드 레이아웃으로 재구성하고 /me에서 실제 값을 불러오도록 수정.

데이터 흐름
MemberPage.initState()
  └─ AuthService.getMe(token)
       └─ GET /me
            (UserResponse + level_source)
                ↓
       setState(_level, _levelSource)
                ↓
       build → 프로필 카드 + 등급 카드 + 로그아웃
실패 시 widget props로 폴백, snackbar로 안내.

주요 변경점

  • 다크 테마 적용 — Scaffold(backgroundColor: bg) + 커스텀 헤더로 머티리얼 기본 AppBar 제거.
  • 프로필 카드 신설 — 이니셜 아바타, 닉네임, 이메일, "현재 등급 + 소스 pill"을 하나의 카드에 통합.
  • 실제 등급/소스 표시 — /me에 level_source 필드 추가. AuthService.getMe() 신규. 더 이상 하드코딩되지 않음.
  • 등급 선택 UI 통일 — RadioListTile(머티리얼 라이트) → _LevelTile(다크 카드). 홈 화면의 _LevelSettingsSheet와 동일한 외관.
  • 로그아웃 버튼 추가 — 확인 다이얼로그 후 onLogout 콜백을 통해 홈 상태 초기화.
