# 로그인 & 회원가입 화면 리디자인 설계

**작성일:** 2026-03-14
**상태:** 승인됨

## 개요

Rexx Strength 앱의 로그인/회원가입 화면을 리디자인한다. 현재 하나의 페이지에 이메일+비밀번호 필드와 버튼 2개만 있는 기본 구조를, 브랜드 임팩트가 있는 로그인 화면과 단계별 회원가입 위저드로 분리한다.

## 설계 결정 요약

| 항목 | 결정 |
|------|------|
| 로그인 스타일 | 소셜 + 신뢰 지표 (Option C) |
| 회원가입 스타일 | 3단계 스텝 바이 스텝 위저드 |
| 프로그레스 바 | 상단 고정, 완료 시 체크마크 + 녹색 연결선 |
| 소셜 로그인 | UI만 구현, 기능은 추후 (가이드 문서 별도 저장) |
| 신뢰 지표 | 하드코딩 (1.2K / 15K+ / 4.8) |
| 운동 선택 UI | 원형 아이콘 + 이미지, 복수 선택 가능 |
| 리액션 버블 | 선택에 따라 다른 친밀감 메시지 표시 |

## 1. 로그인 화면

### 레이아웃
- 상단: 앱 아이콘 (💪) + "REXX Strength" + "AI 자세 분석 코칭"
- 중단: 신뢰 지표 3개 (활성 사용자 1.2K / 자세 평가 15K+ / 만족도 4.8) — 하드코딩
- 하단: 이메일 입력 → 비밀번호 입력 → "로그인" CTA 버튼
- 구분선: "또는"
- 소셜 로그인 버튼: Apple / Google / 카카오 (UI만, 탭 시 "준비 중입니다" 토스트)
- 최하단: "계정이 없으신가요? 회원가입" 링크

### 동작
- 이메일+비밀번호로 기존 `/login` API 호출
- 성공 시 JWT 토큰 저장 후 홈 화면 이동
- "회원가입" 탭 시 회원가입 위저드 화면으로 전환

## 2. 회원가입 위저드

### 공통
- 상단 프로그레스 바: 3개의 원형 스텝 인디케이터 + 연결선
  - 현재 단계: 녹색 배경 + 숫자
  - 완료 단계: 녹색 배경 + 체크마크(✓) + 연결선 녹색 채움
  - 미진행 단계: 반투명 배경 + 숫자
- 각 단계에서 "이전" 버튼으로 뒤로 이동 가능
- Step 1에서 "이미 계정이 있나요? 로그인" 링크

### Step 1 — 계정 정보
**필드:**
- 이메일 주소 (📧 아이콘)
- 비밀번호 (🔒 아이콘, 8자 이상)
- 비밀번호 확인 (🔒 아이콘)

**실시간 검증 칩:**
- "8자 이상" — 충족 시 녹색 ✓
- "영문+숫자" — 충족 시 녹색 ✓
- "일치" — 비밀번호 확인 일치 시 녹색 ✓

**CTA:** "다음 단계 →" (모든 검증 통과 시 활성화)

### Step 2 — 프로필 설정
**필드:**
- 닉네임 (👤 아이콘)
- 신장 (📏 아이콘, cm 단위) / 체중 (⚖️ 아이콘, kg 단위) — 가로 나란히 배치
- "🔒 신체 정보 비공개" 토글 스위치
  - 기본값: ON (비공개)
  - 설명 텍스트: "커뮤니티에서 다른 회원에게 숨깁니다"
- 안내 박스: "ℹ️ 신체 정보는 자세 분석 피드백에 활용됩니다. 공개 설정은 마이페이지에서 변경 가능합니다."

**CTA:** "다음 단계 →"

### Step 3 — 관심 운동 선택
**운동 종목 (원형 아이콘 그리드):**
| 종목 | 아이콘 | 리액션 메시지 |
|------|--------|---------------|
| 3대 운동 | 🏋️ | "오, 3대 운동을 좋아하시는군요! 스쿼트·벤치·데드리프트 자세 분석으로 함께 성장해봐요!" |
| 맨몸 운동 | 🤸 | "어디서든 할 수 있는 맨몸 운동! 기본기가 탄탄하시겠네요!" |
| 유산소 | 🏃 | "꾸준한 유산소 운동, 체력의 기본이죠! 응원합니다!" |
| 요가/필라테스 | 🧘 | "유연성과 코어를 동시에! 자세에 대한 감각이 남다르시겠네요!" |
| 격투기 | 🥊 | "격투기 좋아하시는군요! 강인한 정신력이 느껴집니다!" |
| 수영 | 🏊 | "전신 운동의 왕, 수영! 균형 잡힌 체력을 가지고 계시겠네요!" |

- 복수 선택 가능 (선택 시 녹색 테두리 + 글로우 효과)
- 선택할 때마다 리액션 버블이 업데이트됨 (복수 선택 시 조합 메시지)
- 프로덕션에서는 이모지 대신 실제 이미지(Unsplash 등)로 교체

**CTA:** "🎉 시작하기!" → 회원가입 API 호출 → 홈 화면 이동

## 3. 화면 전환 흐름

```
로그인 화면
├── "로그인" 버튼 → 인증 → 홈 화면
├── "회원가입" 링크 → Step 1 (계정 정보)
│   ├── "다음" → Step 2 (프로필)
│   │   ├── "다음" → Step 3 (관심 운동)
│   │   │   └── "시작하기" → 회원가입 API → 홈 화면
│   │   └── "이전" → Step 1
│   └── "이전" → 로그인 화면
└── 소셜 버튼 → "준비 중입니다" 토스트
```

## 4. 백엔드 변경

### User 모델 확장
기존 필드에 추가:
- `height`: Float, nullable (신장 cm)
- `weight`: Float, nullable (체중 kg)
- `is_body_public`: Boolean, default False (신체 정보 공개 여부)
- `interests`: Text, nullable (관심 운동 JSON 배열, 예: `["powerlifting","bodyweight"]`)

### /register API 변경
기존 요청 본문 (email, username, password)에 추가 필드 수용:
- `height` (optional)
- `weight` (optional)
- `is_body_public` (optional, default: false)
- `interests` (optional, string array)

## 5. 파일 구조 변경

### 새로 생성하는 파일
```
rexx_app/lib/pages/login_page.dart          — 리디자인 (기존 파일 덮어쓰기)
rexx_app/lib/pages/signup/                  — 회원가입 위저드 디렉터리
  signup_page.dart                          — 위저드 컨테이너 (프로그레스 바 + PageView)
  step1_account.dart                        — Step 1 계정 정보
  step2_profile.dart                        — Step 2 프로필 설정
  step3_interests.dart                      — Step 3 관심 운동 선택
docs/social-login-implementation-guide.md   — 소셜 로그인 구현 가이드
```

### 수정하는 파일
```
rexx_server/auth.py                         — User 모델에 필드 추가
rexx_server/main.py                         — /register 엔드포인트 수정
rexx_app/lib/services/auth_service.dart     — register() 메서드에 새 필드 추가
rexx_app/lib/pages/home_screen.dart         — 로그인/회원가입 네비게이션 수정
```
